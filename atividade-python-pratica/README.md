# Gerenciador de Tarefas Semanal em Python

Este é um projeto prático desenvolvido como parte da atividade de programação em Python. O objetivo do script é fornecer uma ferramenta simples e funcional via linha de comando para organizar e gerenciar tarefas do dia a dia.

## Funcionalidades

O script permite ao usuário realizar quatro operações principais:
- **Visualizar:** Lista todas as tarefas atualmente cadastradas.
- **Adicionar:** Permite a inserção de novas pendências na lista.
- **Remover:** Exclui uma tarefa específica baseada no seu número de índice.
- **Sair:** Encerra a execução do programa de forma segura.

## Tecnologias Utilizadas

- **Linguagem:** Python 3
- **Estruturas de Dados:** Listas (`list`) para armazenamento dinâmico.
- **Estruturas de Repetição e Condicionais:** Loops `while` e condicionais `if/elif/else` para o fluxo do menu.
- **Tratamento de Erros:** Blocos `try/except` para evitar falhas caso o usuário digite um caractere inválido na remoção.

## Como Executar o Projeto

### Pré-requisitos
Você precisa ter o **Python 3** instalado em sua máquina.

### Passo a Passo
1. Baixe o arquivo `script.py` ou clone este repositório.
2. Abra o terminal ou o prompt de comando na pasta onde o arquivo está salvo.
3. Execute o comando abaixo:

```bash
python script.py
```

4. Interaja com o menu numérico exibido no terminal.
